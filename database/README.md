# SmartCare Queue - Database

## Overview

SmartCare Queue uses MySQL as the primary database.

The database stores:

- Users
- Patients
- Doctors
- Departments
- Doctor schedules
- Appointments
- Queue tokens
- Queue positions
- Notifications
- Hospital resources
- Emergency alerts

Database Name:

smartcare_queue

## Technology

- MySQL 8.0
- MySQL Workbench
- Git & GitHub

## Database Tables

### 1. users

Stores information about patients, doctors, staff and administrators.

### 2. departments

Stores hospital departments such as General Medicine, Cardiology, Orthopedics and Pediatrics.

### 3. patients

Stores patient-specific information.

Each patient is connected to a user account.

### 4. doctors

Stores doctor information.

Each doctor is connected to a user and a department.

### 5. doctor_schedule

Stores the working schedule and availability of doctors.

### 6. appointments

Stores appointments between patients and doctors.

### 7. queue_entries

Stores digital tokens and queue information.

Important information includes:

- Token number
- Queue position
- Queue status
- Priority
- Estimated waiting time
- Actual waiting time

### 8. notifications

Stores appointment, queue, emergency and system notifications.

### 9. resources

Stores hospital resource information such as:

- Beds
- ICU

### 10. emergency_alerts

Stores emergency patient and ambulance arrival alerts.

## Queue System

The queue works approximately like this:

Patient
↓
Appointment
↓
Queue Entry
↓
Token Number
↓
Queue Position
↓
Estimated Waiting Time

Queue priorities:

- NORMAL
- URGENT
- EMERGENCY

Queue statuses:

- WAITING
- CALLED
- IN_PROGRESS
- COMPLETED
- SKIPPED
- CANCELLED

## Waiting-Time Prediction

The queue_entries table contains:

estimated_wait_minutes

This field can store the waiting-time prediction generated by the backend prediction system.

The prediction can later consider:

- Number of patients waiting
- Queue position
- Patient priority
- Doctor availability
- Average consultation duration

## Setup

### Step 1

Open MySQL Workbench.

### Step 2

Run schema.sql.

This creates the smartcare_queue database and its tables.

### Step 3

Run sample-data.sql.

This inserts sample data.

### Step 4

Select the database:

USE smartcare_queue;

### Step 5

Check the tables:

SHOW TABLES;
